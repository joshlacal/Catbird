# Trending topic media previews

Search, All Topics and the timeline topic carousel share a decorative preview from actual entries in each supplied topic feed. Up to three distinct representative posts contribute image thumbnails, provided link-card thumbnails or available video stills. Quoted images and video stills require independently hydrated post context. Media sources and URLs are deduplicated across representatives. Frozen gallery types support images; unknown media variants remain text fallback. No external page scraping, playback or autoplay is involved.

The wide title sits beside a larger colorful category symbol in the leading avatar position. Category colors are shared across Search and timeline. A fixed 108-point-wide artwork region reserves 86 points for cards and an optional 30 points for participant avatars, including pending, failed and text-only results. Late media cannot move titles or resize timeline cells. Titles wrap fully; large accessibility text moves Search artwork below the description. Decorative marks, media and participant circles stay outside VoiceOver navigation; Reduce Motion removes card rotation.

Topic metadata starts a nonblocking preview batch before individual rows appear. Search and timeline each admit at most six unique links. Both batches and visible rows share two feed-read slots, including the additional quote hydration read. Each feed fetch requests twelve entries; a single optional getPosts read hydrates up to six quote URIs through at most three quote levels. Raw entries are bounded to thirty per topic and twenty topics, with five-minute success and one-minute failure lifetimes. An existing default-labeler feed cache may be reused once per link, for at most twenty links. Current graph/foreground changes clear preview entries and disable old feed reuse. Cancellation and stale completions cannot refill invalidated entries.

Only policy-approved URLs enter the dedicated two-job image prefetcher. It uses the same resized requests as display and Catbird's shared Nuke pipeline, with at most thirty-six image/avatar requests per surface. Departure, replacement, backgrounding and invalidation cancel owned prefetch work without clearing shared caches. Direct feed and quote reads participate in AppState's account-operation barrier; suspension cancels batches, clears raw context and waits for admitted reads before shared-client credentials may change.

Inactivity closes admission before cancellation, including late metadata completions, queued feed execution and image warming. Foreground refresh advances the existing preview revision so visible surfaces start a new bounded batch; departed surfaces have no stored resume callback. Image ownership uses Nuke's complete processed-request identity, including ordered resize processors, decode scale, thumbnail/load options and resource cache/cellular settings. Different resized variants at the same URL release independently; an identical request shared by both surfaces stops only after its last owner departs.

Moderation runs before image/avatar selection and image prefetch, including cache hits. It checks active post/author labels, self-labels, local and server actor/list mutes and blocks, hidden posts, thread mutes, words including alt text/link titles/descriptions/tags, quick filters, language and feed/reply/quote preferences. Quoted supplied records and hydrated posts must agree on URI, CID, author and typed content; every nested context is independently checked. Missing hydration, unavailable/detached quotes, unknown embeds and quoted replies without hydrated parent/root remain text fallback. Link cards also honor existing external-provider hide decisions. All active labels, including informational/custom labels, remain excluded because these decorative cards have no warning/reveal interaction. Negated and expired labels use Catbird's existing label semantics. Selected labelers must exactly match the applied accepted-labeler header, including the default labeler; pending or failed updates suppress previews.

The refinement starts from installed revision `d6065928d1a6fa797f1affe83309f2e111d63589` in an isolated jj workspace. The large selected default feed tile reuses grid selection tint with its own glass namespace. Video navigation closures and audio behavior remain owned by the coordinated video task. Frozen Petrel and overlay source are unchanged. Remote moderation performed in another client while Catbird remains foreground can remain stale until bounded refresh; there is no real-time moderation subscription.

Validation includes typed protocol/cache fixtures, cancellation/coalescing checks, and durable presentation tests for fixed artwork geometry, categories, narrow/light/dark/large-text/RTL layouts. Supplemental standalone checks import prebuilt helper modules; they do not qualify the successor app's account wiring or runtime. The integration owner coordinates the combined app build, app-hosted tests and captures. No phone operation or real-account write belongs to this source task.
