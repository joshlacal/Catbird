## Feed discovery · preserve concurrent server membership
Chose: a feed-only synchronization operation applies captured pending URI edits to the latest server V2 records, preserving unrelated IDs, types, order and preference variants. Legacy feed edits supersede older pending intent; exact revisions are acknowledged after synchronization. V1 Following placement is migrated explicitly. Rejected replacing the entire feed list from local arrays because retry could erase another device's already-saved feed. Reversible before integration acceptance by replacing the feed-specific merge seam and its regression tests. The protocol has no compare-and-swap token, so a remote write strictly between GET and PUT remains outside the guarantee.
